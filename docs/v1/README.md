# v1 documents (MandateManager)

These documents describe the first version, `MandateManager.sol`, where mandates were owned by a wallet and co-signed with a passkey. They are kept because they reference transactions recorded on Monad testnet (`deployments.json`).

The current primitive is `AgentMandates.sol`, a mandate owned by the passkey itself. Start from the [main README](../../README.md).
